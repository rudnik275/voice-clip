Голос → текст → Mac-буфер

voice-clip это закрытый инструмент: диктуешь на телефоне, сервер транскрибирует через OpenAI, результат сразу оказывается в буфере обмена на твоём Mac. Нажал Cmd+V — текст уже там.

Шаг 1

Установка на iPhone / iPad

Это PWA — устанавливается как приложение прямо с браузера, без App Store.

Открывать ТОЛЬКО в Safari — не из Telegram / Mail / VK
  1. 1 Открой эту ссылку в Safari (встроенный браузер iPhone). Из Telegram или Mail ссылка откроется во встроенном вебвью — «Добавить на экран Домой» там недоступно.
  2. 2 Внизу экрана нажми кнопку «Поделиться» (квадратик со стрелкой вверх).
  3. 3 В списке найди и нажми «На экран "Домой"».
  4. 4 Нажми «Добавить» — иконка появится на рабочем столе.
  5. 5 Открывай голосовой буфер всегда через иконку, не через браузер. Только так PWA работает полноэкранно.
скриншот будет здесь — Поделиться → На экран «Домой»
Шаг 2

Разрешение микрофона — один раз навсегда

При первом нажатии на кнопку записи iOS спросит разрешение на микрофон. Нажми «Разрешить» — и больше никогда не спросит.

Если нажал «Не разрешать» или разрешение пропало — исправляется в одно место:

  1. 1 Открой Настройки на iPhone.
  2. 2 Найди Safari (или «voice-clip» если установлена PWA).
  3. 3 Раздел «Разрешения» → Микрофон → выбери «Разрешить».

Почему это важно: iOS переспрашивает каждый раз, если разрешение выдано только «однократно» — это мешает быстрой диктовке. Постоянное разрешение решает проблему.

скриншот будет здесь — iOS Настройки → Микрофон
Опционально

Mac-приложение — глобальный хоткей и автовставка

Без Mac-приложения транскрипт попадает в буфер — жмёшь Cmd+V сам. С приложением всё автоматически: текст вставляется в активное поле сразу после диктовки. Плюс глобальный хоткей, чтобы открыть запись не переключая окна.

Установка при ограничениях macOS (Gatekeeper)

macOS блокирует приложения не из App Store. Это нормально — обходится в два клика:

  1. 1 Открой скачанный .dmg, перетащи voice-clip.app в папку Applications.
  2. 2 Попробуй открыть — macOS скажет «невозможно открыть». Не нажимай «Переместить в корзину».
  3. 3 Зажми Ctrl и кликни на иконку приложения → выбери «Открыть» из меню.
  4. 4 В диалоге снова нажми «Открыть» — после этого macOS запомнит и больше не будет блокировать.
скриншот будет здесь — Ctrl+клик → Открыть

Разрешения после первого запуска

  1. 1 Специальные возможности (Accessibility): macOS попросит разрешение для автовставки текста. Системные настройки → Конфиденциальность → Специальные возможности → включи voice-clip.
  2. 2 Микрофон: разреши, если хочешь диктовать прямо в Mac-приложении (не только с телефона).
скриншот будет здесь — Accessibility permission

Автозапуск при старте Mac

Чтобы приложение запускалось само при входе в систему: Системные настройки → Основные → Объекты входа → «+» → выбери voice-clip.
